# Hi, I'm Olof

- [Bluesky Wrapped](https://www.madebyolof.com/bluesky-wrapped): your year on Bluesky, wrapped up in a personal recap.

Away from the computer, I like cycling, racket sports, exploring Berlin, and getting out into a Swedish forest when I can.
